SEO, Sitemap, & Domain Deployment Guide (atschool.id)

1. File robots.txt

User-agent: *
Allow: /
Sitemap: https://atschool.id/sitemap.xml

2. File sitemap.xml

<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://atschool.id/</loc>
    <lastmod>2026-09-25</lastmod>
    <changefreq>weekly</changefreq>
    <priority>1.0</priority>
  </url>
</urlset>

3. DNS Record Setup for Custom Domain (atschool.id)

Type Name Value / Target
A @ 75.2.60.5 (or Netlify/Cloudflare IP)
CNAME www atschool.id

4. Quick Deploy Checklist

  1. Upload index.html ke GitHub Pages, Netlify, atau Cloudflare Pages.
  2. Tambahkan custom domain atschool.id di dashboard hosting.
  3. Atur DNS A Record & CNAME di registrar domain seperti yang tertera di atas.
  4. Pastikan HTTPS Automatic SSL diterbitkan aktif secara otomatis.
